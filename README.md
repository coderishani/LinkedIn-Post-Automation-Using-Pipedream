# LinkedIn Post Automation Using Pipedream

An automated workflow that creates and publishes a LinkedIn post with text and an image using Pipedream.

## Project Overview

This project demonstrates how Pipedream can be used to automate LinkedIn content publishing through a webhook-triggered workflow.

The workflow:
- Receives a webhook request
- Creates a LinkedIn post
- Adds post text
- Adds an image using an image URL
- Publishes the post automatically

## Workflow

Webhook Trigger
→ LinkedIn Create Post
→ Add Post Text
→ Add Image
→ Publish on LinkedIn

## Tools & Technologies

- Pipedream
- LinkedIn
- Webhooks
- Workflow Automation

## How It Works

1. A webhook triggers the Pipedream workflow.
2. The workflow executes the LinkedIn posting step.
3. The configured post text is added.
4. An image URL is provided.
5. Pipedream publishes the post automatically on LinkedIn.

## Project Result

The workflow was tested successfully and the generated LinkedIn post was verified after publication.
